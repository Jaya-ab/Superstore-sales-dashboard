# Superstore Sales Dashboard

## 📊 Project Overview

This project is a Sales Dashboard created as part of my Data Analytics Internship at SkillCraft Technology.

The dashboard uses the Sample Superstore dataset to analyze sales and profit performance and present key business insights through data visualization.

## 🛠️ Tools & Technologies

- Google Sheets
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## 📈 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Monthly Sales Trend
- Profit by Category
- Regional Sales and Profit Analysis

## 🔍 Key Analysis

The dashboard provides insights into:

- Overall sales performance
- Overall profitability
- Monthly sales trends
- Profit comparison across product categories
- Regional sales and profit performance
